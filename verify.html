Provably Fair Verification

Verify that any game outcome was fair and not manipulated. Enter the server seed and hash to check.

🔐 How Provably Fair Works

  1. Before the game: We generate a random "server seed" and show you its SHA-256 hash
  2. During the game: The outcome is determined by the server seed (which you can't see yet)
  3. After the game: We reveal the actual server seed
  4. Verification: You can hash the revealed seed yourself - if it matches the hash we showed you before, the game was fair

🤔 Why does this prove fairness?

Because we show you the hash before the game, we can't change the seed afterward. Cryptographic hashes are one-way - you can't find a seed that produces a specific hash. So if the seed we reveal matches the hash, we couldn't have cheated.
